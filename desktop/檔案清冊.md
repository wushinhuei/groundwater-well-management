# 檔案清冊（2.0.0）

所有更新流程改由本機執行；使用者依 README 安裝 Python、Node、Chrome 與 gh。node_modules 與本機登入狀態不打包。

| 檔案 | 用途 | 使用方式 |
|---|---|---|
| [README.md](README.md) | 系統總覽、管理目的、本機與雲端分工、快速開始及限制。 | 首次使用先閱讀。 |
| [使用說明.md](使用說明.md) | 安裝、登入、排程、手動操作、日誌及移機的詳細說明。 | 操作前閱讀。 |
| [AGENTS.md](AGENTS.md) | 供 AI agent 或維護者接續工作的架構、資料規則、驗證狀態與待辦。 | 交接維護時閱讀；不是執行程式。 |
| [檔案清冊.md](檔案清冊.md) | 本清冊，逐一列出套件檔案用途。 | 查找檔案時閱讀。 |
| [手動執行更新.bat](手動執行更新.bat) | 手動更新入口，呼叫 Manual-Update.ps1；顯示結果後停留視窗。 | 完成設定與登入後雙擊，每次處理到期佇列中的一批（優先最近三個月份）。 |
| [Manual-Update.ps1](Manual-Update.ps1) | 檢查設定、Node.js、金鑰路徑及 Playwright，呼叫原有更新啟動器並顯示日誌位置。 | 由手動執行更新.bat 呼叫。 |
| [Setup.cmd](Setup.cmd) | 首次設定的雙擊入口。 | 首次使用執行；呼叫 Setup.ps1。 |
| [Setup.ps1](Setup.ps1) | 安裝相依套件、詢問金鑰路徑與起始資料月份、建立本機設定及資料夾權限。 | 由 Setup.cmd 呼叫；既有設定存在時停止。 |
| [Login.cmd](Login.cmd) | 開啟水利署專用瀏覽器供使用者自行輸入帳密及驗證。 | 首次登入或登入過期時執行。 |
| [Verify.cmd](Verify.cmd) | 唯讀查詢 K1140087 的上一完整月份，驗證登入、網頁解析及 Drive 索引讀取。 | 安裝任務前執行；不寫入 Drive、不發布網站。 |
| [Plan.cmd](Plan.cmd) | 讀取井籍索引，顯示到期但尚未完成的批次。 | 盤點待辦時執行；不查詢水利署。 |
| [Run-Now.cmd](Run-Now.cmd) | 直接透過 Run.ps1 執行一批到期更新的原有入口。 | 需先完成設定；一般使用者優先用手動執行更新.bat。 |
| [Run.ps1](Run.ps1) | 排程與手動操作共用啟動器：取得互斥鎖、啟動 Node、保存每日主控台輸出及退出碼。 | 由 CMD／BAT／Windows 任務呼叫。 |
| [Install-Task.cmd](Install-Task.cmd) | 安裝 Windows 排程的雙擊入口。 | 唯讀驗證成功後 24 小時內執行。 |
| [Install-Task.ps1](Install-Task.ps1) | 檢查驗證紀錄與台北時區，建立每日 14:13 的互動式排程。 | 由 Install-Task.cmd 呼叫；已有同名任務時停止。 |
| [Disable-Task.cmd](Disable-Task.cmd) | 停用排程的雙擊入口。 | 暫停更新或移機前執行。 |
| [Disable-Task.ps1](Disable-Task.ps1) | 停用 Groundwater-WRA-Monthly 任務，保留任務及資料。 | 由 Disable-Task.cmd 呼叫。 |
| [Remove-Task.cmd](Remove-Task.cmd) | 移除排程的雙擊入口。 | 不再使用排程時執行，需確認。 |
| [Remove-Task.ps1](Remove-Task.ps1) | 確認後刪除 Windows 任務；保留設定、登入檔及更新紀錄。 | 由 Remove-Task.cmd 呼叫。 |
| [Status.cmd](Status.cmd) | 開啟本機設定、狀態、檢查點與主控台日誌資料夾。 | 查看最近執行狀態時雙擊。 |
| [Open-Log.cmd](Open-Log.cmd) | 開啟 logs 資料夾，供選擇各資料月份的更新日誌。 | 查看逐井更新、缺資料及異常紀錄時雙擊。 |
| [run.cjs](run.cjs) | 主要更新流程：登入、Drive 存取、網頁查詢、斷點續查、資料合併、寫入與讀回驗證。 | 由 Run.ps1 啟動；不要直接雙擊。 |
| [core.cjs](core.cjs) | 純資料邏輯：月份及三批分組、漏跑佇列、表格解析、零值／缺值處理、合併。 | 由 run.cjs 引用，供維護者修改。 |
| [browser-session.cjs](browser-session.cjs) | 水利署 cookie 範圍過濾、Windows DPAPI 加解密及年度欄位選取。 | 由 run.cjs 引用；包內沒有真實登入資料。 |
| [logger.cjs](logger.cjs) | 每月日誌追加、台灣時間、錯誤分類及實際變動數量計算。 | 由 run.cjs 引用。 |
| [tests.cjs](tests.cjs) | 離線驗證月份、跨年、漏跑補查、缺值、零值與合併規則。 | 透過 npm test 執行，不連實站。 |
| [logger-tests.cjs](logger-tests.cjs) | 離線驗證日誌追加、月份歸檔、井名欄位、錯誤摘要與敏感欄位排除。 | 透過 npm test 執行，不連實站。 |
| [package.json](package.json) | 套件名稱、實際版本、Node.js 需求、Playwright 版本與 npm test 指令。 | 由 npm 及維護者讀取；版本以此檔為準。 |
| [integration-tests.cjs](integration-tests.cjs) | 使用模擬瀏覽器及 Drive 回應執行真實 run.cjs 流程，檢查寫入、缺值、並行變更及 429 冷卻。 | npm test 執行，不連實站。 |
| [驗證報告.md](驗證報告.md) | 2026-10-20 離線驗證結果與尚未驗證範圍。 | 接手及部署前閱讀。 |
| [SHA256.json](SHA256.json) | 套件檔案的 SHA-256 校驗碼，不包含此清單自身。 | 檢查內容完整性；修改套件後須重新產生。 |
| [115年9月抽水更新日誌.log](115年9月抽水更新日誌.log) | 依既存證據事後整理的九月結果：95 口更新、9 口未變、7 口缺資料及歷史差異。 | 用記事本閱讀；不是本機排程的實站測試紀錄。 |
| [local-publish.cjs](local-publish.cjs) | 呼叫本機 Python 更新流程，讀取發布狀態；失敗回傳錯誤。 | 參閱 README 的本機安裝與驗證步驟。 |
| [Configure-Local.cmd](Configure-Local.cmd) | 本機 Python／GitHub 發布環境設定入口。 | 參閱 README 的本機安裝與驗證步驟。 |
| [Configure-Local.ps1](Configure-Local.ps1) | 檢查 gh 登入、安裝 Python 依賴、保存執行檔路徑。 | 參閱 README 的本機安裝與驗證步驟。 |
| [Publish-Now.cmd](Publish-Now.cmd) | 只執行本機來源同步、索引與網站發布，不查詢水利署。 | 參閱 README 的本機安裝與驗證步驟。 |
| [publish-tests.py](publish-tests.py) | 驗證無變更不提交、原子提交、分支競爭不強推。 | 參閱 README 的本機安裝與驗證步驟。 |
| [local-sync/publish.py](local-sync/publish.py) | 本機資料流程協調、GitHub 提交及公開網站比對。 | 參閱 README 的本機安裝與驗證步驟。 |
| [local-sync/groundwater_drive_sync.py](local-sync/groundwater_drive_sync.py) | 下載 Drive 井籍／抽水來源，在本機產製並回寫索引。 | 參閱 README 的本機安裝與驗證步驟。 |

## Git 儲存庫版本

本程式位於儲存庫 desktop/，完整 clone 可取得。九月實際更新日誌留在本機交付包，不加入公開 Git 原始碼；文件對該日誌的說明為歷史背景。原始井籍／水權／電費與憑證不在本目錄，仍須另外準備。
